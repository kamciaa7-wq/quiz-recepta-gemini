# Test wiedzy o Recepcie Gemini

## 1. Supabase
Wejdz w Supabase -> SQL Editor -> wklej zawartosc `supabase.sql` -> Run.

## 2. Vercel
1. Utworz konto na Vercel.
2. Dodaj projekt z GitHub albo wrzuc folder przez Vercel CLI.
3. W Settings -> Environment Variables dodaj wartosci z `.env.example`.
4. Deploy.

## 3. Admin
Panel: `/admin`
Haslo: wartosc `ADMIN_PASSWORD`.
